# KeySwitch

Минималистичный переключатель раскладки для Windows 10/11.
Набрал «ghbdtn» вместо «привет» — нажми **Pause**.

**Крошечный и лёгкий:** один файл 280 КБ, без установки и без зависимостей, около 2 МБ памяти и 0% процессора в простое. Полностью открытый код.

## Почему KeySwitch?

Punto Switcher, Caramba и похожие программы стараются угадать раскладку за тебя с помощью больших словарей. Иногда это удобно, но они ошибаются на аббревиатурах, логинах, коде и сленге — и приходится исправлять исправление.

KeySwitch устроен иначе: **ты сам лучше знаешь**, когда набрал не в той раскладке. Одна клавиша — и текст исправлен. Ничего не меняется без твоего ведома, а программа остаётся крошечной, потому что ей не нужны словари.

## Возможности

| Действие | Клавиша по умолчанию |
|---|---|
| Исправить последнее слово | `Pause` |
| Исправить выделенный текст | `Shift+Pause` |
| Сменить регистр выделенного текста | `Ctrl+Pause` |
| Переключить раскладку | `Caps Lock` (обычный Caps Lock — `Shift+Caps Lock`) |

- **Крошечный.** Один exe на 280 КБ, написан на чистом C++ и Windows API — без фреймворков, без сред выполнения, без фоновых служб. Сидит в трее, занимает около 2 МБ памяти и просыпается, только когда ты нажимаешь клавишу.
- **Без автоугадывания.** Программа ничего не исправляет сама — только по твоей команде. Никаких ложных срабатываний.
- **Работает с любыми раскладками** Windows: русской, украинской, немецкой и т.д.
- **Знаки остаются на месте.** Буквы конвертируются, а знаки — те, что ты нажимал: «дела?» → «ltkf?».
- **Повтор по кругу.** Нажми ещё раз — слово перейдёт в следующую раскладку, регистр — в следующий вариант: строчные → Как в предложении → ЗАГЛАВНЫЕ.
- **Сразу печатай дальше.** После исправления курсор стоит в конце текста, выделение снято.
- **Звезда в трее** показывает раскладку: красная — английская, чёрная — любая другая, серая — программа отключена.
- **Тихий звук** при переключении раскладки: для английской повыше, для остальных пониже. Отключается.
- **Не мешает в играх.** В полноэкранных играх отключается сам, Caps Lock и Pause работают в игре как обычно.
- **Исключения.** Список программ, в которых KeySwitch не работает: кнопкой «Обзор…», из списка запущенных или прямо из меню в трее.
- **Любые горячие клавиши** — назначаются в настройках.
- **Интерфейс на русском или английском** — по языку Windows или на выбор в настройках.

## Конфиденциальность

KeySwitch перехватывает клавиатуру — это нужно, чтобы знать, какое слово исправлять. Поэтому важно:

- **Нет сети.** В программе нет ни одной строчки сетевого кода: ничего не отправляет и не проверяет обновления.
- **Ничего не записывает.** В памяти хранятся только клавиши текущего слова в текущем окне, они стираются при Enter, клике мышью или смене окна. На диск пишутся только настройки (`%APPDATA%\KeySwitch\config.ini`).
- **Открытый код.** Весь код — один файл [`src/keyswitch.cpp`](src/keyswitch.cpp), его можно прочитать и проверить.
- **Сборка на GitHub.** `KeySwitch.exe` в [Releases](../../releases) собирается автоматически из этого кода через GitHub Actions — видно, из какого именно коммита.

## Требования

Windows 10 или 11, 64-битная. Работает и на Windows 11 для ARM (например, Parallels на Mac с чипом Apple) — через встроенную эмуляцию x64.

## Установка

1. Скачай `KeySwitch.exe` со страницы [Releases](../../releases/latest).
2. Положи в любую папку и запусти. В трее появится звезда.
3. Двойной клик по звезде — настройки. Там же галочка «Запускать вместе с Windows».

Exe не подписан цифровой подписью, поэтому при первом запуске Windows SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

## Меню в трее

- **Отключать в «…exe»** — добавить текущую программу в исключения (или **Включить в «…exe»** — убрать).
- **Приостановить** — временно выключить всё.
- **Настройки…**, **О программе**, **Выход**.

## Сборка из исходников

**MinGW-w64** (так собирает GitHub Actions):

```
cd src
windres keyswitch.rc -O coff -o keyswitch_res.o
g++ -std=c++17 -O2 -s -municode -mwindows -static keyswitch.cpp keyswitch_res.o -o KeySwitch.exe -luser32 -lshell32 -ladvapi32 -lgdi32 -lwinmm -lcomdlg32
```

**Visual Studio** (Developer Command Prompt):

```
cd src
rc keyswitch.rc
cl /O2 /EHsc /utf-8 /DUNICODE /D_UNICODE keyswitch.cpp keyswitch.res /Fe:KeySwitch.exe /link /SUBSYSTEM:WINDOWS /MANIFEST:NO
```

## Ограничения

- В окнах, запущенных от администратора, не работает, если сам KeySwitch запущен без прав администратора (защита Windows).
- В некоторых играх в оконном режиме и старых программах эмуляция ввода может не сработать — добавь их в исключения.
- На клавиатуре Mac (Boot Camp, Parallels) нет клавиши Pause — назначь другие сочетания в настройках.
